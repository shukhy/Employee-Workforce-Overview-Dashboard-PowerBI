Employee Workforce Overview Dashboard

Project Overview

This Power BI dashboard provides comprehensive insights into workforce performance, employee demographics, hiring trends, job satisfaction, education levels, attrition, and salary metrics. The dashboard helps HR professionals and business leaders monitor workforce health and make data-driven decisions.
